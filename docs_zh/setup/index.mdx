# 设置 Komodo 核心

要运行 Komodo，您需要 Docker。请参阅 [docker 安装文档](https://docs.docker.com/engine/install/)。

### 使用 Docker Compose 部署

- [**使用 MongoDB**](./mongo.mdx)
- [**使用 FerretDB** (Postgres)](./ferretdb.mdx)

:::info
有些系统[不支持运行最新版本的 MongoDB](https://github.com/moghtech/komodo/issues/59)。
使用这些系统的用户应改用 FerretDB。
:::
