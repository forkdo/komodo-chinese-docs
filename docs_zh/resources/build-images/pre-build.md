# 构建前命令

有时需要在运行 `docker build` 之前运行一个命令，您可以在*构建前*部分配置此命令。

*构建前*需要传递两个字段。第一个是*路径*，它会更改工作目录。要在仓库的根目录中运行该命令，只需传递 `.`。第二个字段是*命令*，这是在克隆仓库后要执行的 shell 命令。

例如，假设您的仓库中有一个名为 `scripts` 的文件夹，其中包含一个 shell 脚本 `on-clone.sh`。您可以将*路径*指定为 `scripts`，将命令指定为 `sh on-clone.sh`。或者，您可以将*路径*指定为 `.`，然后命令将是 `sh scripts/on-clone.sh`。两种方法都可以。
