# 容器管理

docker 容器的生命周期更像一个虚拟机。它们可以被创建、启动、停止和销毁。Komodo 将显示容器的状态，并提供一个 API 来管理所有容器的生命周期。

这在内部是通过为请求的操作（docker stop、docker start 等）运行适当的 docker 命令来实现的。

### 停止容器

有时您想停止一个正在运行的应用程序，但保留其日志和配置，以便稍后重新启动或查看日志。这更像是用其当前配置*暂停*应用程序，因为再次启动容器时不会更改任何配置（例如环境变量、卷挂载等）。

请注意，为了使用更新的配置重新启动应用程序，必须*重新部署*它。再次停止和启动容器将保留容器最初创建时的所有配置。

### 容器重新部署

重新部署是销毁容器并重新创建它的操作。如果您更新部署配置，这些更改在容器重新部署之前不会生效。请注意，这将销毁以前的容器日志以及容器本身。
